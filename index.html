SHEET 03 / PROCESS
DESIGN APPROACH

PROCESS

THINK

These core principles that drive every design decision I make from first sketch to final product.
01 NODE // 01

CLARITY OVER COMPLEXITY

Every design decision is a choice between adding complexity and removing friction. I default to the option that makes the user's path shorter, clearer, and more intuitive even when that means cutting work I'm proud of.

02 NODE // 02

STRUCTURE OVER CHAOS

My Avionics engineering background taught me that systems must be precise, redundant, and fail-safe. I bring that same rigour to information architecture, component systems, and design documentation.

03 NODE // 03

USER NEED OVER DESIGN EGO

The most beautiful interface is the one user don't notice because it just works. Research first, pixel second. I validate assumptions with real users before I ever open Figma.
